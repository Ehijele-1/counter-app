# Counter App

A simple and interactive counter application built with HTML, CSS, and JavaScript.

## Features

* Increase the counter
* Decrease the counter
* Reset the counter
* Display the last action performed
* Perform actions using keyboard controls
* Update the interface dynamically based on user interactions

## Keyboard Controls

 Key         | Action         |
 ----------- | -------------- |
 `ArrowUp`   | Increase count |
 `ArrowDown` | Decrease count |
 r         | Reset count    |

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Practised

This project was built to reinforce JavaScript fundamentals, including:

* DOM manipulation

* Keyboard events
* Functions
* Updating element content dynamically
* Handling user interactions
* Tracking application state
